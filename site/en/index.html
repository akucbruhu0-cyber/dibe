What DIBE does

  • Live transcript

    Finished sentences appear within a second or a few. A grey line shows the sentence still being spoken. Pause, resume, edit while it writes.

  • Any source, almost any language

    Audio or video files, the microphone, system audio, links from YouTube and more. Almost every language, offline.

  • A summary on your terms

    Write what you need and the AI summarizes. Attach images, PDFs and text files. Works with Gemini, Claude, any OpenAI-compatible server or local Ollama.

  • Ask the recording

    Ask a question about a recording and get an answer, sometimes with a chart, timeline or table when it helps. Charts use only numbers that were said.

  • Exports that look right

    SRT, VTT, TXT, HTML, JSON, Word and a designed PDF: real headings, tables, justified text. Add your follow-up questions if you like.

  • Also on your phone

    An Android app that records and transcribes on the phone itself, offline. Recordings survive crashes.

DIBE in action

Your transcript stays with you.

DIBE has no analytics, no telemetry, no accounts and no update checks. Transcription runs on your computer, and the local server listens only on 127.0.0.1 behind a token that changes on every launch.

  • Without internet it keeps working.
  • It uses the network only when you ask: a model download, a link, an AI provider you configured.
  • Nothing runs in the background.

First launch

macOS

DIBE is not notarized by Apple, so macOS blocks the first launch. Drag DIBE.app into Applications, then: System Settings → Privacy & Security → Open Anyway.

xattr -dr com.apple.quarantine /Applications/DIBE.app
Windows

Windows may show "Windows protected your PC". Choose More info → Run anyway.

Android

Open the file on your phone and allow installing from this source.

DIBE is built and tested on Apple Silicon Macs. The Intel and Windows builds are produced automatically and not yet tested. If something breaks, tell us (opens in a new tab).

Questions

Does DIBE really work offline?

Yes. Once a model is downloaded, transcription runs entirely on your computer. The internet is needed only for model downloads, links, and cloud summaries if you pick that.

What does it cost?

Nothing. DIBE is free and open source (MIT). AI summaries need a key from the provider you choose. Gemini offers a free key, and Settings has a short video on how to get it.

What do I need to run it?

A powerful computer, because transcription runs on it. A Mac with Apple Silicon is the tested setup. On a phone: 64-bit Android from about 2019.

Why does my computer warn me?

DIBE is not code-signed or notarized by Apple. That is expected, and you allow it once (see Download).

Does it work in Hebrew?

Yes, alongside almost every other language. The interface is translated into many languages.

How is it different from Vibe?

DIBE is built on Vibe and keeps everything it does. It adds live transcription, a sturdier recorder, Gemini for summaries, and no analytics at all.

Does it update itself?

No. Download the new version from the releases page (opens in a new tab).
